# Admin Panel Project

This folder contains the standalone admin panel for Darool Uloom Hidayatul Islam.

## Run locally

1. Open a terminal inside `admin`
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3001/admin/login`

## Notes

- Admin source files are inside `admin/src/Component/Admin`
- The admin app uses `localStorage` for persistence
- The frontend app remains in the project root
